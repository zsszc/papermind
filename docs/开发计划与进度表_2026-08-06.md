# PaperMind 新开发计划与进度表（2026-08-06）

## 1. 目标与执行原则

本计划承接 Phase A–H 与 Batch 7–11 的既有逻辑。项目当前已经具备完整业务功能，后续主线从“继续堆功能”切换为“先建立可信 Harness，再消除发布阻断，最后以稳定基准提升 RAG 与 UI”。

所有批次严格执行 `Harness 基线 → SDD spec/plan/tasks → TDD RED/GREEN/REFACTOR → 全量回归 → 测试报告 → 中文 Conventional Commit → push`。没有稳定基准时，RAG 变化只记为实验结果，不直接修改生产默认策略。
