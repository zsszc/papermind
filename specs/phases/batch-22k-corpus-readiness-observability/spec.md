# Batch 22K 规格：真实语料就绪度可观测性

## 1. 目标

把 Batch 22J 的私有 v2 readiness 聚合结果接入本地应用，让用户无需命令行即可看到
补库进度，并在达到 12 篇唯一新论文前持续阻止 QA 构建和盲测。

## 2. 范围

- 新增只读后端聚合接口，返回物理文件、唯一内容、重复副本、v1 覆盖、v2 合格和缺口计数。
- 在统计页增加 Benchmark v2 就绪卡片、明确的 PASS/WAIT 状态与补库提示。
- 复用 `eval.benchmark_v2` 的审计语义；不得在 API 层复制一套身份判定逻辑。
- 本批不删除/移动重复 PDF，不构建 QA，不运行 holdout，不调用 LLM 或网络服务。

## 3. 隐私与硬 Gate

- API 和 UI 只能暴露聚合计数、阈值与布尔状态，不得返回文件名、路径、标题、DOI、
  paper UID、PDF SHA、重复组成员或正文片段。
- 缺失私有 manifest、异常 PDF、软链接、身份冲突或审计错误必须 fail closed；UI 显示
  不可就绪，不得把未知状态当作 0 或 PASS。
- 后端、前端和 CLI 对同一语料快照的聚合计数必须一致。
- 接口为只读操作，不修改数据库、论文文件或私有评测制品。

## 4. 验收标准

- 后端契约/隐私/异常测试与前端卡片交互测试先 RED 后 GREEN。
- 真实库显示 36 个物理 PDF、19 份唯一内容、17 个副本、1 篇合格、缺 11 篇并处于 WAIT。
- 全量后端、前端、Electron、lint、build、公开 RAG Gate 与依赖检查通过。
